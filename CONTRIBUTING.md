# Contributing to AExplorer

Thanks for your interest in contributing to AExplorer!  
This project is a lightweight CLI file explorer written in Rust, and contributions of all kinds are welcome.

---

## Getting Started

### 1. Fork the repository

Click the **Fork** button on GitHub and clone your fork:
